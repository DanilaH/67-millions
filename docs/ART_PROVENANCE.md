# Production art batch, 2026-10-01

Original images were generated with OpenAI image generation for this project, using the repository Visual Bible as a brief. These are AI-generated illustrations in a hand-painted dirty-cartoon style; they are not claimed to be a manually painted commission. No external franchise/person/brand assets were supplied. The key-art image was used as a style/character reference for subsequent images.

Retained sources in assets-src: keyart.png (1672×941), map.png (1672×941), scene-atlas.png (1672×941, four independent backgrounds), barry-states.png (1774×887, two states), interactables.png (source dimensions recorded in manifest). public/art/manifest.json records source SHA-256, dimensions, atlas cells, logical frames, load classes and runtime footprint. Run npm run art:build to reproduce exports; generation is not repeated by setup/build.

Brief: broad irregular ink contours, chunky gouache, worn cheap repaired surfaces, muted charcoal/rust/mustard/mold; original stocky brown-jacket/mustard-tie Barry with long invoice; tired seller with delivery bag; no real logos, celebrity likeness requests, flags or political iconography. Map includes seven modest locations. Background atlas has quiet kitchen, trash yard, street puzzle, empty machine backplate. Interactables are a clean plate, tied bag, street crate and delivery worker icon. Gameplay dirt, hit areas, route geometry, obstacles and physics remain live and authoritative.

Runtime choices: map uses 1.5× logical presentation; Barry 1.5×; backgrounds use native atlas-cell resolution (decorative surfaces can be softer than interactive geometry); interactables use 384px logical untrimmed cells. This intentionally does not upscale scene-cell sources into fake 2× masters. Work art loads when the scene starts; map and Barry load before presentable bootstrap. Text stays on solid readable panels. The cached sprite pool follows authoritative positions; gameplay is not driven by sprites/animation. Plinko uses small shared pin glyphs, static line Graphics and a bounded pool of ball sprites and renders the painted frame as cropped border strips; no full-screen RenderTexture cache is used.

WebP batch: 830,728 encoded bytes; 16,604,896 decoded RGBA proxy bytes if all 11 images are resident. AVIF companions are validated for dimensions and alpha. These are asset budgets, not a measured total GPU-memory claim. Browser/device evidence is recorded separately.

T061 limitation: generated native key art is 1672×941. The required >=2560×1440 master is not satisfied. The native source, marketing WebP and 320px thumbnail are retained in release/media, with exact provenance and an explicit false minimum2560MasterSatisfied field. No resize is presented as a higher-resolution original. Final key-art approval and target-device visual acceptance remain outstanding.
