# Проверка распределения после пользовательского плейтеста — 2026-10-05

Пользователь сообщил о росте 500 → примерно 47 млн за около пяти минут без выхода из казино и проигрыше по здоровью. Это наблюдение одного забега; его seed и последовательность покупок неизвестны.

## Метод

HEAD/main перед проверкой: b5aebb98c5b66643eb4bdf3675d921702efae0db. Конфиг не изменён, SHA-256: 7fe6c5c2a3ae98cbb1c1eaf81172097d0bd7cfbd259fee499f9c593214a3cd2c.
В этом изменении расширен существующий shared-world адаптер только счётчиками карманов и срабатываний. Используются production createBarePlinko и настройки Resolver из Phaser. Предыдущие браузерные parity fixtures зелёные; новый браузерный прогон всех seeds не проводился.

35 вариантов × 2000 независимых оплаченных корней = 70 000 запусков. Парные seeds между вариантами, новый поток xorshift32 от 67106554. Все запуски завершились до ограничения 3600 тиков. Ставка 500, начальные деньги 100000 для изоляции доски; это не воспроизведение полного забега с 500. Страховка выключена. Доля края означает хотя бы одного потомка в кармане 0 или 9 на оплаченный запуск; pockets — количество всех завершившихся шаров, включая потомков.

Воспроизведение:

```sh
node --import tsx simulation/full-game/upgradeAudit.ts 2000 reports/pacing/2026-10-05-pockets 67106554
```

Числовые результаты: summary.json; выплаты каждого корня: samples.csv.gz. Исходный прогон выполнен временным entrypoint с тем же алгоритмом, затем диагностические дополнения перенесены в существующий upgradeAudit.ts без изменения алгоритма.

## Выводы

- Голая доска: 1,912× вместо targetBareEV 0,85. Край 8,05% вместо идеального биномиального ориентира 0,391% (ориентир формы, не обязательная точная вероятность). Карманы слева направо: 80 / 88 / 129 / 295 / 437 / 404 / 225 / 171 / 90 / 81. Центр вместе 42,05%. Предыдущая независимая выборка дала 1,992× и 8,9% края. Стартовая физика не соответствует назначению.
- Общее снижение края после всей прокачки НЕ подтверждено: maximum 24,25% против base 8,05%. Нельзя приписать конкретному пользовательскому забегу причину без порядка покупок/seed.
- Возврат L1 → L2 реально ухудшает результат: 2,350× → 1,879×; край 14,95% → 9,25%. Средняя парная разница −0,47025 ставки, SE 0,06961. В предыдущей независимой выборке −0,38225, SE 0,09588. Пины на каждом уровне заменяются, а не накапливаются; возврат сохраняет боковую координату. L3 → L4 край тоже уменьшается (17,95% → 16,85%), хотя средняя выплата немного растёт. Меньше краёв не всегда означает меньше дохода.
- Направляющие в изоляции монотонно повышают край: 8,05 → 9,20 → 10,90 → 14,25 → 19,95%. Их прежняя калибровка на standalone Matter не доказывает корректность текущей игры.
- Раздвоение срабатывает у 24,95% корней голой доски, но максимум меняет средний возврат лишь 1,912× → 1,923×. Проблема не в полном отсутствии контактов: пин r8c4 находится в последнем ряду, эффект возникает поздно. Точную пользу перемещения надо измерять отдельно. L1 делит стоимость на 0,48 + 0,48, то есть сам по себе уменьшает сумму стоимости потомков.
- Улучшения выплат, усилитель, лимит ставки и страховка не изменяют геометрию/направление шара; первые четыре изученные группы выплат/усилителя сохраняют одинаковое распределение карманов. Страховка и лимит проверены по коду, их последовательные экономические эффекты этим прогоном не оценивались.
- Максимальная доска 37,126×; без улучшения джекпот-выплат 5,200×. Это средние с редкими большими выплатами, не гарантированный доход. Лимит ставки увеличивается в пять раз на каждом уровне, масштабируя уже положительный стартовый доход.

Сначала экспериментально откалибровать базовую геометрию/физику на Phaser-совместимом движке, сохранить редкие края и средний возврат около 0,85; подтвердить независимыми seeds и браузером. Затем заново подобрать уровни возврата, направляющие и положение раздвоения на исправленной основе. Только после этого калибровать экономический рост и повторять полный сценарий с 500. Не компенсировать физику повышением цен или усилением голода. Старые оплаченные броски должны завершаться на прежней физике.
